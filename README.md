# 📝 TO-DO LIST

> **"오늘 한 일이 내일의 나를 만든다."**  
> 매일의 목표를 기록하고 달성률을 확인하며 스스로를 성장시키는 모바일 맞춤형 투두리스트 웹 서비스입니다.

---

## 🌟 주요 기능 (Key Features)

- **실시간 날짜 & 시각 표시**: 상단에 현재 날짜와 시각이 실시간으로 업데이트됩니다.
- **달성률(%) 게이지바**: 체크박스를 선택할 때마다 실시간으로 달성 퍼센트와 게이지바가 채워집니다.
- **100% 달성 축하 메시지**: 모든 할 일을 마치면 `Clear!` 메시지가 뜹니다.
- **일일 동기부여 문구**: 날짜별로 매일 새로운 동기부여 명언이 하단에 업데이트됩니다.
- **계층형 세부 할 일 & 페이지네이션**: 상위 과업 아래 세부 할 일을 추가·접기/펼치기 할 수 있으며, 한 페이지당 5개 단위로 깔끔하게 탐색할 수 있습니다.
- **클라우드 실시간 동기화 및 JSON 백업**: `LocalStorage` 자동 저장은 물론, Firebase 계정을 통한 멀티 디바이스 실시간 동기화 및 JSON 백업·복원 기능을 지원합니다.
- **모바일 최적화 반응형 UI**: 미니멀하고 직관적인 흑백 톤의 디스플레이와 iOS 홈 화면 웹앱(PWA) 추가를 지원합니다.

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS)
- **Backend / Cloud**: Firebase Authentication, Cloud Firestore, LocalStorage
- **Deployment**: GitHub Pages

## 🛠️ 서비스 개선일지 (Service Improvement Log)

> 초기 MVP(v1.0) 출시 후 실생활에서 매일 과업을 관리하며 발견한 **사용자 불편(Pain Point)**을 정의하고, **계층형 데이터 구조·모바일 UX·클라우드 동기화** 관점에서 고도화한 기록입니다.

### ① [데이터/로직] 실제 등록 과업 수 기반 동적 진행률 계산 로직 개선
* **문제 인식 (Pain Point):** 초기 버전(v1.0)은 기본 7개의 할 일 슬롯을 기준으로 달성률을 계산해, 사용자가 하루에 6개의 과업만 등록하고 모두 완료해도 진행률이 100%에 도달하지 않는 데이터 불일치가 발생함.
* **해결 및 구현 (Action):** 고정된 기본 항목 개수를 제거하고 실제 등록된 유효 과업 수를 분모로 계산하도록 로직을 수정했으며, 100% 달성 시 시각적 보상(`Clear!`) 메시지를 노출함.
* **기획적 기대 효과 (Result):** 실제 업무량과 일치하는 정확한 달성률 지표를 제공하여 데이터 신뢰성을 확보하고, 사용자의 목표 달성 성취감을 강화함.

### ② [서비스 구조] 상·하위 계층형 체크리스트 및 완료 상태 자동 연동
* **문제 인식 (Pain Point):** 전공 과목 학습이나 프로젝트처럼 여러 세부 단계가 필요한 업무에서, 하위 과업을 모두 끝내지 않았는데도 상위 업무가 완료 처리되는 구조적 허점이 있었음.
* **해결 및 구현 (Action):** 상위 과업 아래 세부 할 일(Sub-task)을 생성하는 계층 구조를 도입하고, 모든 하위 항목이 체크되어야만 상위 항목이 완료로 전환되도록 상태 연동 로직을 설계함.
* **기획적 기대 효과 (Result):** 복합 과업의 누락을 원천 방지하고, 큰 목표를 실행 가능한 단위로 쪼개어 관리하는 체계적인 일정 관리 프로세스를 구축함.

### ③ [UI/UX] 아코디언(접기/펼치기)·Enter 연속 입력·페이지네이션(5개) 적용
* **문제 인식 (Pain Point):** 세부 할 일을 등록할 때마다 입력창을 다시 클릭해야 하는 번거로움이 있었고, 목록이 길어지면 모바일 뷰포트에서 과도한 스크롤이 발생해 핵심 과업 파악이 어려웠음.
* **해결 및 구현 (Action):** 
  * `Enter` 키 입력 시 즉시 다음 세부 입력창으로 포커스가 이동하는 연속 입력 UX 구현
  * 세부 목록 기본 접힘(Accordion) 처리 및 클릭 시 선택적 펼침 UI 적용
  * 한 페이지당 주요 과업 5개만 노출하는 페이지네이션(Pagination) 도입
* **기획적 기대 효과 (Result):** 입력 동선의 마찰(Friction)을 줄여 작성 속도를 높이고, 모바일 화면 내 정보 밀도를 최적화하여 탐색 피로도를 대폭 낮춤.

### ④ [UX/접근성] 유틸리티 드롭다운 통합 및 모바일 웹앱(iOS) 최적화
* **문제 인식 (Pain Point):** 설정·백업·초기화 버튼이 상단에 개별 노출되어 UI가 산만했고, 모바일에서 매번 브라우저 주소창을 통해 접속해야 해 일상적인 리텐션(재방문)이 떨어졌음.
* **해결 및 구현 (Action):** `Reset` 버튼 옆에 알림·백업 기능을 묶은 드롭다운 메뉴를 배치해 상단을 정돈하고, 반응형 CSS 및 iOS 홈 화면 추가 메타 태그·아이콘을 적용해 독립 앱 형태로 구동되도록 개선함.
* **기획적 기대 효과 (Result):** 핵심 기능과 보조 기능의 시각적 위계를 분리하고, 네이티브 앱에 준하는 원터치 접근성을 확보해 일일 사용 빈도를 극대화함.

### ⑤ [데이터/인프라] Firebase 계정 동기화 및 JSON 백업·복원 시스템 구축
* **문제 인식 (Pain Point):** 브라우저 `LocalStorage` 저장 방식은 PC와 모바일 간 일정 연동이 불가능하며, 캐시 삭제 시 데이터가 유실될 위험이 존재했음.
* **해결 및 구현 (Action):** Firebase Authentication(이메일 로그인) 및 Firestore를 연동해 사용자 UID별 실시간 클라우드 동기화와 기존 로컬 데이터 마이그레이션 기능을 구현했으며, 별도의 JSON 내보내기·불러오기(형식 검증 포함) 기능을 추가함.
* **기획적 기대 효과 (Result):** 기기 종속성을 탈피한 멀티 디바이스 업무 환경을 구축하고, 사용자에게 데이터 백업·복구 통제권을 부여해 서비스 안정성과 신뢰도를 높임.
